# Modul Belajar Mandiri: Array & String (Bahasa C)

Repositori ini berisi paket belajar mandiri terstruktur untuk menguasai materi **Array (1D, 2D, Fungsi, Sorting)** dan **String (<string.h>, gets, Manipulasi Teks)** pada Bahasa C hingga level **HOTS**.

## Urutan Belajar yang Disarankan

1. **[Buku Pegangan Materi Lengkap (18 Kepingan Lego)](./buku_materi_lengkap_array_string.md)**
   Pelajari konsep dari nol beserta 18 pola koding dasar (*building blocks*) lengkap dengan contoh kasus sederhana agar siap merakit solusi sendiri.
2. **[Ringkasan Cepat / Cheat-Sheet Teori](./modul_belajar_array_dan_string.md)**
   Tabel ringkasan aturan Array, parameter fungsi, gets, kode ASCII, dan fungsi pustaka <string.h>.
3. **[Lembar Latihan Soal Bertingkat (Murni Soal)](./latihan_soal_array_string.md)**
   Berisi 3 soal bertingkat **Array**, 3 soal bertingkat **String** (<string.h>), dan **1 Soal Puncak HOTS** gabungan Array & String beserta contoh eksekusi input–output.
4. **[Panduan Penyelesaian: Dekomposisi & Penjelasan Tiap Gerakan](./panduan_penyelesaian_dekomposisi.md)**
   Buka panduan ini saat mengerjakan soal. Tidak membocorkan kode jadi, melainkan membedah keinginan soal, memecah masalah (*dekomposisi*), menyusun langkah kerja, dan menjelaskan apa yang terjadi di memori pada setiap gerakan.
